# Дизайн-процесс и необязательный React-пресет

Этот документ нужен, чтобы первая версия с интерфейсом выглядела цельно и
соответствовала задаче. Он не делает React обязательным и не задаёт один стиль
для всех продуктов. Сначала выбираются формат продукта и визуальное направление,
и только затем — инструменты.

Визуальный характер можно адаптировать под продукт, но интерфейс должен
оставаться спокойным, читаемым, мобильным и доступным.

## Необязательные зависимости для React

Только если для проекта уже выбран React, интерфейсу действительно нужны иконки
и осмысленное движение, а `package.json` уже создан, можно установить:

```sh
npm install lucide-react motion
```

- `lucide-react` — единый набор аккуратных контурных иконок.
- `motion` — пружинные переходы, появление блоков и реакция элементов на
  нажатие.

Перед установкой проверь совместимость актуальных стабильных версий с выбранным
React и Node.js. Итоговые версии зафиксирует lock-файл конкретного проекта.
Если используется не npm, применяй уже выбранный менеджер пакетов. В чистой
заготовке эти библиотеки не устанавливаются.

Не устанавливать по умолчанию `shadcn/ui`, Magic UI, готовый Apple-шаблон,
другую библиотеку компонентов или дополнительную библиотеку анимации.
Если продукту позже понадобится одна из них, сначала объяснить конкретную пользу
и влияние на сложность.

Импортировать Motion для React так:

```tsx
import { motion } from "motion/react";
```

Импортировать из Lucide только используемые иконки, а не весь набор:

```tsx
import { ArrowRight, Check, Upload } from "lucide-react";
```

## Основа CSS

Стили писать вручную в CSS. Использовать переменные, чтобы цвета, размеры и
эффекты не расходились между экранами. Начальная палитра:

```css
:root {
  color-scheme: light;

  --font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;

  --color-bg: #f1f1ec;
  --color-surface: rgba(255, 255, 255, 0.68);
  --color-surface-strong: rgba(255, 255, 255, 0.88);
  --color-border: rgba(255, 255, 255, 0.78);
  --color-text: #172019;
  --color-text-muted: #657069;
  --color-accent: #5f7c67;
  --color-accent-strong: #46614e;

  --radius-sm: 12px;
  --radius-md: 18px;
  --radius-lg: 28px;

  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;
  --space-6: 32px;
  --space-7: 48px;

  --shadow-soft:
    0 1px 2px rgba(23, 32, 25, 0.04),
    0 12px 32px rgba(23, 32, 25, 0.08),
    inset 0 1px 0 rgba(255, 255, 255, 0.72);
}
```

Это отправная точка, а не обязательный бренд каждого проекта. Допускается
менять палитру и характер поверхностей под карточку, сохраняя контраст,
последовательность и небольшой набор токенов.

## Визуальные принципы

- Системный шрифт: `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, затем
  `sans-serif`. Не загружать внешний шрифт без продуктовой причины.
- Фон молочно-серый, без чистого холодного белого на всём экране.
- Основные поверхности слегка полупрозрачные; `backdrop-filter: blur(...)`
  использовать только там, где под поверхностью действительно есть фон.
- Границы тонкие и светлые, но видимые на целевом экране.
- Тени мягкие и многослойные; не использовать одну тяжёлую чёрную тень.
- Основной текст тёмный, вторичный — приглушённый, акцент — спокойный зелёный.
- Крупные заголовки имеют плотный межбуквенный интервал, но русский текст не
  должен слипаться или терять читаемость.
- Все скругления и отступы берутся из общей шкалы.
- На телефоне рабочее действие располагается раньше описательных и
  декоративных блоков.
- Не имитировать macOS или iOS буквально и не копировать интерфейс Apple.

## Иконки

- Использовать один визуальный набор — Lucide.
- Размер, цвет и толщина линий одинаковы для элементов одного уровня.
- Иконка не заменяет текст там, где действие может быть непонятно новичку.
- Декоративной иконке задать `aria-hidden="true"`.
- Кнопке только с иконкой дать доступное имя через `aria-label`.

## Движение

- Простые изменения цвета и прозрачности делать обычным CSS.
- Motion использовать для появления смысловых блоков, изменения компоновки,
  раскрытия, успешного результата и тактильной реакции кнопки.
- Для нажатия достаточно небольшого изменения, например
  `whileTap={{ scale: 0.98 }}`.
- Не анимировать всё подряд, не задерживать первое действие и не использовать
  движение как украшение без смысла.
- Уважать системную настройку уменьшения движения через
  `prefers-reduced-motion` и возможности Motion.
- Не анимировать большие области с тяжёлым blur или box-shadow, если это
  вызывает рывки на телефоне.

## Порядок реализации

1. Определить главное действие и мобильную компоновку.
2. Подключить токены и базовую типографику.
3. Собрать интерфейс обычными семантическими элементами React и CSS.
4. Добавить только необходимые иконки Lucide.
5. Убедиться, что сценарий работает без анимации.
6. Добавить несколько осмысленных переходов Motion.
7. Проверить мобильный и широкий экран по правилам из `AGENTS.md`.
8. Исправить визуальные дефекты до демонстрации пользователю.

## Критерий готовности

Интерфейс не считается готовым только потому, что добавлены blur, тени и
анимация. Он готов, когда главное действие заметно, русский текст читается,
компоновка не ломается на телефоне, управление доступно с клавиатуры, движение
не мешает, а браузерная проверка пройдена.

## Канонический UI-кит FINDOCTOR / Brilliant Event (`shadcn/ui Maia: Mist + Champagne`)

Все существующие и будущие страницы, карточки, модальные окна, табы, фильтры и
формы авторизации в проекте **обязаны** строиться строго из единого набора
токенов и классов в `src/client/styles/globals.css`. Запрещено придумывать новые
цвета выделения, градиенты или нестандартные рамки.

### 1. Цветовые токены и единый стандарт выделения «Шампань» (`Champagne`)

- **Фон страницы (`--background`):** `#f8f9fa` (`Mist`)
- **Карточки и модальные окна (`--card`):** `#ffffff`, рамка `1px solid var(--border)` (`#e3e6e8`), скругление `var(--radius-lg)` (`10px`)
- **Основной текст (`--foreground`):** `#1e2328`, вторичный (`--muted-foreground`): `#646e78`
- **Единое активное выделение (табы, переключатели, чипы, выбранные счета, фильтры, статьи):**
  - Фон: `var(--champagne-bg)` (`#f6f2ea`)
  - Рамка: `1px solid var(--champagne-border)` (`#c5b08e`)
  - Текст: `var(--foreground)` (`#1e2328`), `font-weight: 600`
  - Иконка внутри активного элемента: `var(--champagne-icon)` (`#8c734b`)
  - Фокус поля ввода / селекта: `border-color: #c5b08e; box-shadow: 0 0 0 2px rgba(197, 176, 142, 0.25);`

### 2. Готовые строительные блоки (Blueprints)

При создании любого нового экрана или окна берём готовые классы без изобретения новых стилей:

1. **Шапка раздела (`.ui-page-header` / `.reports-header-card`)**:
   - Слева: иконка в квадрате Шампань (`.ui-page-header-icon` / `.reports-header-icon`: `38×38px`, фон `#f6f2ea`, рамка `#e5dac7`, иконка `#8c734b`), заголовок `1.25rem` (`font-weight: 800`) и короткий подзаголовок `0.8rem`.
   - Справа: группа кнопок действий (`.ui-page-header-actions` / `.reports-actions-group`).
2. **Карточка контента (`.ui-card` / `.glass-panel`)**:
   - Белая поверхность `--card`, рамка `1px solid var(--border)`, радиус `10px`, тень `var(--shadow-sm)`, внутренний отступ `20px`.
3. **Переключатели режимов, табы и чипы фильтрации (`.ui-tabs-bar`, `.ui-tab-pill`, `.ui-chip`)**:
   - В активном состоянии всегда используют класс `.active` / `.ui-tab-pill-active` / `.ui-chip-active` (подсветка Шампань `#f6f2ea` + рамка `#c5b08e`).
4. **Диалоговое / модальное окно (`.ui-dialog-backdrop` + `.ui-dialog` / `.quick-entry-bottom-sheet`)**:
   - Компактное окно по центру экрана (`max-width: 540px`, `padding: 18px 20px`, `border-radius: 10px`), плотная сетка в 2 колонки для парных полей (например, Мероприятие + Дата), основная тёмная кнопка подтверждения внизу (`.btn-modal-submit` / `.ui-btn-primary`).
5. **Поля ввода и выпадающие списки (`.ui-input`, `.ui-select`, `.event-select-input`, `.date-compact-input`)**:
   - Компактная высота `36px–38px`, радиус `6px` (`--radius-sm`), при фокусе — кольцо Шампань (`#c5b08e`).
6. **Кнопки действий**:
   - Главная кнопка (`.ui-btn-primary` / `.btn-modal-submit`): графитовый фон `var(--primary)` (`#272b30`), белый текст `#fbfbfa`.
   - Вторичная кнопка (`.ui-btn-secondary` / `.reports-print-btn`): белый фон, рамка `1px solid var(--border)`.
   - Кнопка быстрого создания элемента на месте (`.ui-btn-dashed` / `.btn-category-inline-add`): пунктирная рамка `1px dashed #cbd5e1`, при наведении — подсветка Шампань (`#f6f2ea` / `#c5b08e`).
