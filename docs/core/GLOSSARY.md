# Словарь проекта

> Codex заполняет этот файл только устойчивыми понятиями конкретного проекта.
> Один термин должен обозначать одно и то же во всех экранах, документах и коде.

## Продуктовые термины

Пока не определены. Добавляются после получения карточки проекта.

Формат записи:

```text
- **Название для человека** (`NameInCode`) — короткое и однозначное объяснение.
```

## Технические термины для пользователя

- **Локальная версия** — проект, который доступен только на компьютере автора.
- **Публичное демо** — тестовая ссылка с вымышленными данными для небольшой
  группы пользователей.
- **Рабочий продукт** — версия для реального использования и реальных данных.

## Что не добавлять

- случайные понятия из примеров других проектов;
- разные названия одного и того же объекта;
- внутренний жаргон, который не помогает понять продукт.
