# Правила оформления коммитов в Git

1. **Язык сообщений:** Все названия и описания Git-коммитов оформляются строго на русском языке.
2. **Простота и понятность:** Формулируй смысл изменений простым, ясным языком, понятным человеку без глубоких технических знаний (без сухого жаргона).
3. **Формат:** Краткий понятный префикс действия + суть сделанного.
   Примеры:
   - `доработка: добавили кнопку быстрого ввода расходов`
   - `исправление: убрали мелькание нулевого баланса при перезагрузке страницы`
   - `дизайн: обновили цвета карточек счетов`
   - `настройка: подключили синхронизацию базы данных Supabase`

4. **Запрет автоматической отправки (git push):**
   - **НИКОГДА не делать `git push` самостоятельно** во время диалога или промежуточных доработок.
   - Все изменения пишем и проверяем строго локально.
   - Коммиты и отправку в удалённый репозиторий GitHub делаем **только в самом конце сессии**, когда пользователь проверил результат, утвердил его и дал прямое указание отправить.
